# Research: Intent Landscape Mapping — 2026-07-26

## Applied to: EXTRACTION.md — adding landscape exploration after X extraction

### The Gap

EXTRACTION finds X (real problem behind stated Y). But it assumes X is THE one. There's no step exploring whether X is the best framing among many alternatives — at different abstraction levels, system boundaries, perspectives, and constraint configurations.

### The Six Techniques

1. **Ladder of Abstraction** (Hayakawa 1939) — Move X up (Why?) and down (How?) 3 levels each. The sweet spot is abstract enough to have optionality, concrete enough to act on.

2. **System Boundary Reframing** (Checkland SSM, CATWOE) — Change customers, actors, worldview, owners. Each change produces a different valid X.

3. **Horizontal Five Whys** (breadth extension of Ohno) — At each level of the causal chain, ask "What ELSE could cause this?" Sibling framings with the same root cause.

4. **Lakoff Framing Lenses** — View X through 6 orthogonal value frames: Efficiency, Equity, Reliability, Experience, Cost, Safety. Each lens produces a different X.

5. **Johari Window for Intent** — Open (known-known), Blind spot (others see it), Hidden (known but unsaid), Unknown (unimagined). Surface the other quadrants.

6. **Constraint Relaxation** (Knoblich et al. 1999) — List every constraint implicit in X. For each assumed constraint, ask: "Without this, what would X look like?"

### Protocol (15 minutes)

1. LADDER: 3 up (Why?), 3 down (How?) — find altitude
2. BOUNDARY: CATWOE elements — reframe system
3. HORIZONTAL: "What else?" — find siblings
4. LENSES: 6 value frames — find perspectives
5. RELAX: Remove assumed constraints — find hidden alternatives
6. CONSOLIDATE: Merge duplicates, discard non-viable, keep 3-7 candidates
7. CHOOSE: Strengthen or pivot
