# Research: Early Exit Mechanisms & Seriousness Gate — 2026-07-27

## Applied to: Development Protocol — adding SERIOUSNESS GATE between EXTRACTION and FUNDAMENTALS

### The Gap

The protocol assumes COMMIT by default after EXTRACTION. Every extracted X proceeds to FUNDAMENTALS (5-10 days of validation). There's no "is this even worth the first 5 steps?" filter.

### Proposed: SERIOUSNESS GATE (30 min, between EXTRACTION and FUNDAMENTALS)

Phase 1 — Commitment Probe (5 min):

- $100 Bet: "Would you bet $100 this leads to something real within 30 days?"
- If-You-Couldn't-Build: "Would you still want X solved if you couldn't build it?"
- Appetite Test: "5 hours this week to validate the riskiest assumption?"
- Recent Behavior: "What have you done about X in the past 7 days?"

Phase 2 — Dimension Scoring (20 min, 5 dimensions 0-20):

1. Problem Severity — real pain, moderate, mild, vitamin
2. Personal Fit — unfair advantage or learning curve
3. Validation Confidence — tested or pure guess
4. Cost of Being Wrong (inverted — higher is better)
5. Urgency — forcing function or anytime

Phase 3 — Kill Criteria (5 min):

1. Name the killer assumption (falsifiable sentence)
2. Pre-commit the off-ramp (observable signal + date)
3. Write decision journal entry

### Exit Outcomes

| Score | Decision                                  |
| ----- | ----------------------------------------- |
| >= 65 | COMMIT — proceed to FUNDAMENTALS          |
| 35-64 | SCHEDULE — park with revisit date         |
| < 35  | DROP — record why, no revisit for 90 days |
